# Equity Atlas

Equity Atlas is a company screener with a deterministic CFA valuation engine. It separates the company universe, reported facts, model suitability, estimates, and the evidence behind each result. A blocked model carries a reason.

- **Public:** [Equity Atlas on GitHub Pages](https://austinmermans.github.io/equity-atlas/) shows official Taiwan exchange closes, capitalization estimates and exchange multiples for 50 issuers alongside SEC filings for 170 issuers. The scheduled build fetches official filings and exchange data, including verified public copies when needed. Optional local imports stay in the browser.
- **Local:** The valuation edition includes market capitalization, reported ratios, model decisions, scenario ranges, and a cycle view. It runs with Python 3.11+ and has no runtime packages.

The public and local builds check each issuer's latest annual period against SEC submissions. When Company Facts lacks that period, it tries the SEC XBRL instance first. For reviewed accessions, it can then download an issuer's or regulator's public copy of the same 20-F and extract its consolidated statement tables using Poppler's `pdftotext`. For reviewed HDFC Bank, Sony and TSMC filings, the next fallback is a free Open10K workbook derived from the SEC Financial Statement and Notes data sets. The build verifies the CIK, fiscal-year filing link, statement scope and reporting currency, and reconciles statement totals before using the values. The screener counts direct SEC extraction, public filing copies and SEC-derived workbooks separately and links the exact filing and downloaded source. New fallback accessions need a reviewed profile. Extraction errors retain earlier available filings and appear in the issuer's data gaps. A reviewed amendment that leaves consolidated statements intact links to the amendment while keeping the original accession on each fact. For interims, the build requests a filing instance if Company Facts lacks the standalone quarter or applicable year-to-date window. For supported issuers it can then read the exact accession from the issuer's extracted XBRL, Inline XBRL archive or a reviewed PDF copy of the filed 10-Q. Reviewed PDF profiles require an accession and validated statement layout. Southern Company's September 2026 interim also supports exact SEC-rendered statement tables delivered by Canli Capital's free public connector. The build verifies the consolidated table titles, accession, currency, date columns and accounting identities before accepting the quarter or year-to-date facts. A verified registrant succession preserves the predecessor's annual evidence and tracks new filings under the successor's CIK. Reviewed claim disclosures supplement a statement from the same accession after its reported totals tie out. Local valuation uses disclosed carrying amounts for temporary equity and equity-classified hybrid claims. Statement-dependent models require the latest verified annual period, and material unresolved claims prevent use of an enterprise-value bridge.

Reviewed annual income statements can also supply revenue and operating profit from exact SEC-rendered rows. The screener shows each signed component and links its table. Revenue definitions that change, such as removing affiliate income or excise taxes, start a new comparable margin history. Issuer-specific gaps identify where the filed presentation requires a separate operating and financing reconciliation. The annual depreciation and amortization rules reuse a reviewed issuer’s line scopes on subsequent filings after checking the new accession, currency, fiscal column, consolidated operating cash flow and any applicable reconciliation. The published company detail keeps combined adjustments with impairment or other costs separate. A changed filing layout appears in the company’s data gaps.

```sh
export ATLAS_SEC_USER_AGENT='Equity Atlas your-contact@example.com'
python3 -m equity_atlas --limit 100 --out data/pilot
python3 -m equity_atlas --limit 250 --out data/expanded
python3 -m http.server 8764 --bind 127.0.0.1 --directory data/expanded
```

Open http://127.0.0.1:8764, or use **Open snapshot** at the Pages site and select `data/expanded/snapshot.json`. For a local file-only launch, open `data/expanded/index.html` and select the snapshot manually. `--offline` reuses the most recent cached source files; it does not advance the market snapshot date. `--ranking PATH` accepts a data export with `Rank,Name,Symbol,marketcap,country` columns, sorted by USD full issuer capitalization; file modification time is treated as the capture time. One row per issuer is required, with a listing-qualified symbol for non-US companies and one cap across economically equivalent classes. The default CompaniesMarketCap download is a delayed provider snapshot for local research. Its values and results computed from them are kept out of Git and Pages. Use a feed that grants the necessary rights before redistributing market data.

```sh
python3 -m unittest discover -s tests -v
python3 -m equity_atlas --public public-issuers.csv --open-market --out data/public-site
python3 scripts/verify_public.py data/public-site/snapshot.json
```

The public workflow runs weekdays at 10:23 UTC and supports a manual refresh. It reuses accession-scoped downloads between runs while fetching submissions, Company Facts and exchange inputs separately. A build that falls below 80% recent annual coverage fails before deployment. The public view carries the build date, quote date, and filing periods independently. The exchange’s dated daily quote report provides closing prices when its OpenAPI feed is unavailable. For a scheduled local market run, use `scripts/refresh-market.sh` with the same SEC user agent, optionally `ATLAS_LIMIT` and `ATLAS_RANKING`. It preserves dated run outputs and updates `data/latest` only on success. Set the working directory and interpreter path explicitly in any external scheduler.
